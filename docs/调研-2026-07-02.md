# LVGL 可视化设计器生态调研(2026-07-02)

> 四路串行联网调研的汇总存档。规划见 [PLAN.md](PLAN.md)。

## 一、LVGL 官方 Editor(LVGL Pro)

- 产品名 **LVGL Pro**,核心是 XML Editor。仓库 [lvgl/lvgl_editor](https://github.com/lvgl/lvgl_editor)(仓库只放 docs/examples,**编辑器本体闭源**),官网 [lvgl.io/pro](https://lvgl.io/pro)。
- 已是正式版:v1.0.0 = 2025-10-22,当前稳定 v1.2.1(2026-05-22),v2.0.0-beta(2026-06-25,加 Design Mode 事件编辑、responsive targets、内存分析等)。
- **订阅制**:Community 免费(只能用在线版 viewer.lvgl.io + 公开 GitHub 仓库,**不能保存**);Starter $1000/年(公司年收入≤$250k);Business $3000/年;Enterprise 定制(独享"编辑器嵌入自家应用"能力)。
- 形态:桌面 Electron App + 在线版 [viewer.lvgl.io](https://viewer.lvgl.io) + CLI(校验/生成C/UI测试/截图)+ Figma 插件 + VSCode 扩展。预览是**真 LVGL 渲染**,自定义 C widget 用本地 emsdk 编进预览。
- XML → C 代码导出、设备端运行时加载 XML 双路径都成熟。
- **不支持 LVGL 8.x**(lv_xml 是 9.3+ 功能,8.x 永远不会有)。

## 二、EEZ Studio

- [eez-open/studio](https://github.com/eez-open/studio),**GPL-3.0 开源**,非常活跃(v0.28.0 = 2026-06-24,约 1-3 个月一版),1714 stars。风险:实质单人开发(mvladic 占 96% commits),Envox 公司维护。
- **LVGL 版本支持:8.4.0 / 9.2.2 / 9.3.0 / 9.4.0 / 9.5.0** 五版并行(源码 `packages/project-editor/lvgl/lvgl-versions.ts`),每版独立的坐标系/图片格式/事件常量/样式属性名映射。
- **41 个 widget 拖拽设计**,基本覆盖 LVGL 全部内置控件;Grid/Flex 布局、样式继承、多语言、中文日历都有。
- 技术栈:Electron 39 + React 18 + TS 5.6 + MobX。**无网页版**(官方无计划)。网页化阻碍:better-sqlite3/serialport/usb/koffi(全是仪器控制功能,LVGL 场景可砍)、fs、Docker Full Simulator、Electron 壳。
- **预览 = LVGL 各版本 Emscripten 编成 WASM 在 Web Worker 里真渲染**(`lvgl_runtime_v8.4.0.wasm` ... `v9.5.0.wasm`,由 [eez-open/studio-wasm-libs](https://github.com/eez-open/studio-wasm-libs) 产出)。另有 Docker 全仿真把用户真实 C 代码整体编 WASM 在浏览器跑。
- C 导出:标准 `src/ui/` 源码组(ui.c/screens.c/images.c/actions.h...),EEZ Flow 完全可选(no-flow 模板)。历史上出过"选 9.x 生成 8.x API"这类回归,升版后需重验证。

## 四、浏览器端技术底座(全部现成可用)

- [lvgl/lv_web_emscripten](https://github.com/lvgl/lv_web_emscripten):官方 WASM 工程,活跃(2025-11),LVGL 9.x + SDL2-emscripten 渲到 canvas,`emcmake cmake` 一条龙出单文件 HTML(`-s USE_SDL=2 -s SINGLE_FILE=1`,32MB 初始堆)。
- **lv_xml 运行时(9.4)**:`LV_USE_XML` 开启;`lv_xml_register_component_from_data()`(内存字符串注册)+ `lv_xml_component_unregister()` + `lv_xml_create_screen()` → **JS 喂 XML 字符串热重载完全可行**(viewer.lvgl.io 活证)。覆盖:全部内置 widget parser、styles(渐变/grid/scroll-snap)、subjects 数据绑定(bind_value/bind_text/bind_flag_if_*)、事件、timeline 动画、字体/图片/const/翻译注册、UI 测试。**硬限制**:自定义 widget 必须 C 编译进 WASM,只有 component/screen 能纯运行时加载。
- 素材转换有现成 JS 实现:lv_font_conv(npm)、lv_img_conv——可跑在浏览器里,v8/v9 图片格式不同要各转一份。
- sim.lvgl.io 证明 v8.3 也能编 WASM(MicroPython 模拟器 8.3/9.0 并存);8.4 编 WASM 需自己搭工程(官方只维护 9.x)。

## 五、⚠️ LVGL XML 许可红线

- XML **loader 代码**(lv_xml)随 LVGL MIT 开源,固件里随便用。
- 但 **XML 格式规范版权归 LVGL LLC**:未经书面许可,禁止制作**公开分发**的"处理该 XML 格式的 UI editor / visual builder / layout designer / code generator"(无论是否开源免费)。**内部私用工具豁免**。授权联系 lvgl@lvgl.io。
- 来源:https://lvgl.io/docs/open/9.4/details/xml/xml/license.html
- → 自研工具的**中间格式必须用自有 schema**;LVGL XML 只作为内部预览通道(内部部署豁免),若将来开源/公开发布,改为 JS→C 桥直接建控件,或申请授权。

## 六、LVGL 8.4 → 9.x 断裂点(影响双版本代码生成的部分)

- 命名批量改:`btn→button`、`btnmatrix→buttonmatrix`、`img→image`、`zoom→scale`、`angle→rotation`、`scr→screen`、`del→delete`、`lv_obj_clear_flag→lv_obj_remove_flag`、`lv_coord_t→int32_t`、`lv_event_send→lv_obj_send_event` —— 纯机械映射,代码生成器模板可消化。
- 结构性坑:**lv_meter 在 9.x 删除**(改 lv_scale,无一对一等价)、**lv_msg 删除**(改 observer/subject)、chart ticks 移除、msgbox/tabview 内部结构变了。
- 颜色/图片:v9 `lv_color_t` 恒为 RGB888;图片格式头不同,**素材要按两套格式各转一份**。
- disp/indev 驱动 API 完全不同 —— 但属移植层不属 UI 层,与设计器无关。
- **结论:提供"8.4 兼容模式"把 widget/样式限制到公共子集,双导出用映射表,可行。**
