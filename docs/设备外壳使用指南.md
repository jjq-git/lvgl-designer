# 设备外壳使用指南

本文介绍 LVGL Designer 中的设备显示预设、外壳预览、圆屏裁切和 Controller Profile。核心原则是：显示预设决定真实画布规格，设备外壳只用于编辑预览，Controller Profile 用于构建和发布校验。

如需通过自然语言新建或修改界面，请参阅 [AI 画 UI 使用指南](AI画UI使用指南.md)。

## 1. 三个核心概念

```text
显示预设
  ├─ 决定 Display Profile 的分辨率和形状
  ├─ 决定所有屏幕共用的 LVGL framebuffer
  └─ 用于匹配内置 SVG 外壳

设备外壳预览
  ├─ 在编辑画布中展示产品外观和显示开口
  └─ 不进入导出的 LVGL UI

Controller Profile
  ├─ 描述构建目标、外壳、显示引用和物理控制能力
  └─ 用于发布前的跨引用校验
```

### 1.1 显示预设和 Display Profile

顶部第一个长下拉框是设备显示预设。它决定：

- 逻辑宽度和高度；
- 矩形或圆形；
- LVGL framebuffer 尺寸；
- 画布坐标范围；
- 圆屏遮罩；
- 可匹配的设备外壳。

显示规格属于项目级配置，一个项目中的所有 Screen 共用同一个 Display Profile。将项目从 1080×720 矩形屏切换为 240×240 圆屏后，`main`、`settings` 等所有屏幕都会按新规格预览。

不同分辨率或不同形状的产品版本建议分别建立工程。同一个工程适合维护同一显示规格下的多个页面。

### 1.2 设备外壳预览

设备外壳是编辑器中的 SVG 陈列层，用来观察界面放入产品外观后的效果。以下内容都不会导出：

- SVG 外壳；
- 编辑器灰色工作区；
- 选择框和缩放手柄；
- 对齐参考线；
- 画布工具按钮。

真正导出的内容只有显示开口内的 LVGL UI。

外壳通过显示宽度、高度和形状精确匹配。自定义显示规格没有对应外壳时，外壳切换按钮会被禁用。

### 1.3 Controller Profile

顶部第二个下拉框用于选择 Controller Profile。它属于构建目标元数据，负责把 UI、Display Profile 和具体控制器关联起来。

`裸屏（无外壳）`表示使用内置的 screen-only Controller。它不会自动隐藏编辑画布上的 SVG 外壳，因此以下状态是正常的：

- Controller 显示“裸屏（无外壳）”；
- 画布仍显示匹配设备的 SVG 外壳；
- 导出结果只包含显示区域内的 UI。

## 2. 内置设备预设

当前离线快照包含以下预设：

| 型号 | 名称 | 逻辑分辨率 | 形状 | 物理尺寸 | 说明 |
| --- | --- | ---: | --- | --- | --- |
| WF2D-8620 | 86 圆屏 | 240×240 | 圆形 | 86×86 mm | 当前内置圆屏预设，带圆形开口外壳 |
| WF2D-1040 | 6B 屏幕 | 1080×720 | 矩形 | 159×97 mm | 6.1 英寸矩形屏 |
| WF2D-1030 | 6A 屏幕 | 1440×720 | 矩形 | 159×97 mm | 5.9 英寸宽屏 |
| WF2D-1050 | 7 屏幕 | 1024×600 | 矩形 | 179×113 mm | 7 英寸矩形屏 |
| WF2D-8630 | 86 方屏 | 480×480 | 矩形 | 86×86 mm | 使用 Demo 逻辑画布，硬件分辨率待登记 |

有发布权限时，设计器会尝试从目标站点设备清单读取最新预设。读取失败时继续使用离线快照。

## 3. 选择和切换设备

### 3.1 手动选择设备型号

1. 打开顶部第一个设备下拉框。
2. 选择目标型号。
3. 等待 LVGL 9.5 WASM 预览重新加载。
4. 确认画布宽高和形状正确。
5. 检查外壳开口是否与 framebuffer 对齐。

切换设备预设会修改整个项目，并进入撤销历史。

### 3.2 切换圆屏

选择 `WF2D-8620` 后，项目会切换到 240×240 圆形 Display Profile。此时：

- 顶部设备型号显示 WF2D-8620；
- 画布使用 240×240 坐标系；
- 四角被圆形遮罩裁掉；
- 有匹配外壳时通过圆形开口显示内容；
- 所有已有屏幕都会使用圆屏规格。

若只想查看圆形风格组件而不改变项目规格，不要切换 Display Profile；可在当前矩形页面中使用圆形控件。但这种做法不等于真实圆屏。

### 3.3 从圆屏切回矩形屏

从设备下拉框选择 WF2D-1040、WF2D-1030、WF2D-1050 或 WF2D-8630。切换后应检查原圆屏页面的布局，因为固定坐标不会自动适配新的宽高比例。

## 4. 显示和隐藏外壳

画布右上角工具组的最后一个按钮用于切换外壳：

- 按钮高亮：显示设备外壳；
- 按钮未高亮：隐藏设备外壳，只看 framebuffer；
- 按钮禁用：当前显示规格没有匹配的内置外壳。

隐藏外壳不会改变项目显示规格，也不会把圆屏变成矩形屏。

推荐在设计过程中交替检查两种视图：

1. 隐藏外壳，检查像素画布和控件边界；
2. 显示外壳，检查产品整体视觉效果和开口遮挡。

## 5. 圆屏布局和安全区

### 5.1 圆屏裁切原理

圆屏仍使用方形像素缓冲，但有效显示区域是其内切圆。对 240×240 圆屏：

- 圆心为 `(120,120)`；
- 半径为 `120`；
- 四角位于有效圆外；
- 有外壳时由外壳开口呈现圆形区域；
- 无外壳时由 Overlay 绘制遮罩和圆周边界。

### 5.2 安全区建议

- 标题不要贴近圆周顶部；
- 长按钮不要横跨圆的最大直径边缘；
- 主要数值放在中心区域；
- 长文本优先换行、缩短或改为图标；
- 列表和表格在圆屏中应减少列数；
- 交互控件建议距离圆周至少 12–18 px；
- 最终应在显示和隐藏外壳两种视图下检查。

### 5.3 圆屏内容被裁切

处理顺序：

1. 点击“适应窗口”确认不是视图缩放问题；
2. 隐藏外壳直接检查 framebuffer；
3. 选中被裁切控件并缩小尺寸；
4. 将控件向圆心移动；
5. 减少标题或按钮文字长度；
6. 重新检查运行模式。

## 6. 画布视图控制

| 操作 | 用途 |
| --- | --- |
| 撤销、重做 | 回退或恢复工程编辑 |
| 缩放百分比 | 显示当前视图比例 |
| 适应窗口 | 将显示区域和外壳缩放到可视区 |
| 重置视图 | 恢复 100% 并居中 |
| 外壳按钮 | 显示或隐藏设备外壳 |

鼠标和键盘操作：

- `Ctrl + 滚轮`：缩放；
- 按住空格拖动：平移；
- `Shift + 1`：适应窗口；
- 方向键：选中控件移动 1 px；
- `Shift + 方向键`：选中控件移动 10 px。

切换设备规格或活动屏幕后，画布会自动以 100% 缩放重新居中。

## 7. 外壳和导出

### 7.1 导出内容

导出的 C/H、构建清单和设备端 framebuffer 不包含编辑器 SVG 外壳。外壳仅用于设计阶段预览。

### 7.2 发布前检查

发布前确认：

- Display Profile 与目标分辨率一致；
- Controller Profile 已选择；
- Controller 的 `displayRef` 与 UI 的 `designDisplayRef` 一致；
- 圆屏内容没有进入四角无效区域；
- 外壳隐藏后 UI 仍然完整；
- 色彩格式已经确认；
- BuildTarget 跨引用校验通过。

## 8. 常见问题

### 8.1 圆屏外面仍有方形区域

方形区域通常是设备 SVG 的外边界或编辑器工作区，不是 framebuffer。判断真实显示区域时看设备开口和圆形遮罩。隐藏外壳后可直接检查圆形 framebuffer。

### 8.2 外壳按钮不可点击

当前宽、高、形状没有匹配的内置外壳。请选择正式预设，或为自定义规格补充设备外壳清单和 SVG 资源。

### 8.3 选择“裸屏”后仍显示外壳

“裸屏”是 Controller Profile，画布外壳是编辑器预览，两者互不等价。点击画布右上角外壳按钮即可隐藏预览。

### 8.4 切换设备后布局变乱

不同分辨率之间不会自动完成响应式重排。应针对目标规格重新调整固定坐标和尺寸，或建立独立工程维护设备变体。

### 8.5 中文显示为方框

这是字体字形缺失，不是外壳故障。内置 Montserrat 只包含英文和数字，需要导入中文字体并在控件样式中使用。参见 [素材管线说明](asset-pipeline.md)。

## 9. 推荐工作流程

### 9.1 新建圆屏产品

1. 新建独立工程。
2. 选择 WF2D-8620。
3. 选择 Controller Profile。
4. 创建或生成各个屏幕。
5. 在隐藏外壳状态下检查 framebuffer。
6. 在显示外壳状态下检查产品效果。
7. 进入运行模式验证交互。
8. 保存并执行导出前校验。

### 9.2 验收清单

- 顶部设备型号正确；
- 分辨率和形状正确；
- 外壳开口与画布对齐；
- 圆屏内容位于安全区；
- 外壳隐藏后 framebuffer 完整；
- 所有屏幕都适配当前项目规格；
- Controller、Display 和 BuildTarget 引用一致；
- 导出结果不包含编辑器外壳资源。
