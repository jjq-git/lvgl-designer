# 静音仓操作界面示例

本目录包含针对五种设备外壳独立排版的静音仓操作界面工程。每个工程都有五个可导航屏幕：总览、空气与通风、灯光、专注模式、设置。

| 工程 | 画布 | 版式 |
| --- | --- | --- |
| `WF2D-8620-quiet-pod.lvproj.json` | 240×240 圆形 | 圆屏单焦点、前后翻页 |
| `WF2D-1040-quiet-pod.lvproj.json` | 1080×720 矩形 | 侧栏导航、双栏信息区 |
| `WF2D-1030-quiet-pod.lvproj.json` | 1440×720 矩形 | 超宽侧栏、多卡片信息区 |
| `WF2D-1050-quiet-pod.lvproj.json` | 1024×600 矩形 | 紧凑横屏布局 |
| `WF2D-8630-quiet-pod.lvproj.json` | 480×480 矩形 Demo 画布 | 方屏底部导航、双列卡片 |

## 打开方式

在设计器左上角点击“打开”，选择对应的 `.lvproj.json` 文件。设计器会根据工程的逻辑分辨率和形状自动匹配正确的设备外壳；WF2D-8620 会显示真正的圆形 240×240 画布。

画布文案采用不依赖外部字体的英文短词，中文用于项目、屏幕和对象的展示名称，避免默认 Montserrat 字体缺少中文字形时显示方框。

## 状态与交互

- 屏幕导航按钮已连接 `screen_load`。
- 灯光、风机、自动换气和勿扰开关绑定 Subject。
- 亮度、色温、风速、CO2、噪声、温湿度均建立了 Subject。
- 场景按钮会写入专注模式或灯光状态。

重新生成示例：

```powershell
corepack pnpm generate:quiet-pod-demos
```
