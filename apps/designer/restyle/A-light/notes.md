# 方案 A「Apple 官网亮色」— 设计要点与风险

产物:`styles.css`(完整可直接替换 `src/styles.css`,覆盖原文件全部 87 个选择器,esbuild 语法校验通过)。
截图证据(playwright 实测,dev server + 运行时注入新 CSS,未动 src):
`a-light-main.png`(圆屏+选中手柄)/ `a-light-rect.png`(方屏陈列投影)/ `a-light-styletab.png`(样式页+palette hover)/ `a-light-ctxmenu.png`(磨砂右键菜单)。

## 设计要点(5 条)

1. **apple.com 灰阶体系**:页面底 #f5f5f7、面板纯白、文字 #1d1d1f/#6e6e73,全部集中在 `:root` 变量;并保留 `--bg/--bg2/--fg-dim` 等旧名别名,第三方/漏网引用不裸奔。
2. **画布 = 产品陈列台**:stage 弃棋盘格改 #e8e8ed 素色;LVGL canvas 加三层投影(1px ring + 近影 + 远影)像官网产品图;**圆屏遮罩用 CSS 覆盖 SVG 表现属性改成与陈列台同色不透明**,圆屏直接呈现为一块真实圆形屏 + hairline 圆环。
3. **overlay 精修(纯 CSS 覆盖,不动 TSX)**:选择框/手柄/hover/落点/参考线的描边色全部由 CSS 接管(#0071e3 系 + #ff2d55 参考线);选择框加 1px 白色 halo,蓝色画面上仍可辨;线宽是 1/zoom 反补偿的 SVG 属性,刻意不碰。
4. **控件语言统一成苹果件**:按钮全胶囊(主按钮 #0071e3→hover #0077ed),检查器选项卡改成白胶囊分段控件,右键菜单/工具条磨砂玻璃(saturate(180%) blur(20px)),选中行实心 accent 白字,细滚动条,一律 0.2s ease。
5. **可用性不倒退**:字号维持 13px/11px 原密度,行距/命中区只增不减;正文与次要文字对比 ≥4.5:1(#6e6e73 白底 5.3:1、主按钮白字 4.7:1、选中行白字 4.7:1、rt 徽章绿/橙 ≥4.9:1);`:focus-visible` 全局 2px accent 环,文本控件焦点改 accent 边框 + 3px 光晕;disabled 保持 0.4 透明度可辨。

## 最不确定的 2 个风险点

1. **「未设置」灰显 (#98989d) 低于 4.5:1**:prop-row unset 的 label 和占位默认值刻意用更浅灰表达"未设置/默认"语义(与原深色版 opacity 0.65 的机制对等,非倒退),但严格按红线量它只有约 3.3:1。若用户要求占位符也达标,把 `--fg-unset` 提到 #767678 即可,代价是"已设/未设"一眼区分度变弱。
2. **canvas 投影随 zoom 缩放**:box-shadow 挂在被 scale 的 `.world` 内,zoom 8× 时远影会放大成 ~300px 的大软影(视觉上等价于"把产品照放大",实测 1×~2× 很好看,极限倍率下略夸张);圆屏遮罩不透明化后会盖掉方形投影、只留圆环,是有意取舍——若想要圆屏也带投影,需动 TSX 加圆形阴影元素,纯 CSS 做不到。
